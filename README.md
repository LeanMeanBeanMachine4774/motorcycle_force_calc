# Dependencies
This script requires numpy to function, it is recommended this is done within a virtual environment.
Create a python virtual environment by navigating to the project's folder in a terminal and running:
```
python -m venv .venv
```
or if on macOS or Linux running:
```
python3 -m venv .venv
```
Once the environment is created and activated, ensure you have pip installed and run
```
pip install -r requirements.txt
```
